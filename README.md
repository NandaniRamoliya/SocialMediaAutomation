# SocialMediaAutomation

An AI social media employee for the company. It handles research, strategy, content
creation, quality checks, human approval, publishing, engagement and reporting across
**Instagram, Facebook, LinkedIn, YouTube, Threads and X**.

The human only approves (one tap on Telegram/Slack/WhatsApp). Everything else runs on a
schedule, and low-risk work moves past the approval step over time as it proves reliable.
